How it works

The Mathematics Behind the Magic

Image Input

28 × 28 × 1

Your drawing becomes a grid of 784 grayscale pixel values.

Convolution

(I ∗ K)(x, y)

Small filters slide over the image to detect edges, curves and strokes.

ReLU

f(x) = max(0, x)

Keeps positive signals and drops negatives, adding non-linearity.

Max Pooling

max(2 × 2)

Shrinks feature maps while keeping the strongest features.

Softmax

eᶻⁱ / ∑ eᶻʲ

Turns final scores into probabilities for digits 0–9.

Each layer learns more abstract patterns — from simple lines to full digit shapes — until the final layer votes on the answer.

Model Information

This project uses my own custom-trained Convolutional Neural Network, trained on the MNIST handwritten digit dataset using TensorFlow / Keras. The model is served through a Python Flask API — no external AI service or third-party pretrained model is used.
